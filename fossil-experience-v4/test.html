Use this environment before students train the real artifacts. Test sessions use simulated recognition and are logged as TEST, separate from live AI Day evidence.

1. Visitor Test

Open this on the device acting as the visitor. Choose Object 1, 2, or 3. Recognition is simulated, so no trained model or physical artifact is required.

2. Observer Test

Open this on a second device. The visitor's selected object should appear automatically as a recent active TEST session. Tap that session and submit an observation.

3. What to verify

Confirm that the selected object appears in the Observer Tool, the observer can pair without typing a Study Code, the visitor completes the flow, and both records appear in the Sheet with Mode = test.
